حلويات الحلبي — إصدار Cloudflare (بدون Supabase)
================================================

ما الذي تغيّر؟
- أزلنا اعتماد المتجر ولوحة الإدارة على Supabase بالكامل.
- طلبات الزبائن تُرسل إلى /api/orders وتُحفظ في Cloudflare D1.
- المنتجات تُقرأ من D1 وتُدار من لوحة /admin/.
- صور المنتجات التي يرفعها المدير تُحفظ كبيانات صور صغيرة داخل D1؛ لا حاجة إلى R2 أو إضافة وسيلة دفع.
- حد رفع الصورة 1 ميغابايت، والأنواع المدعومة JPG وPNG وWEBP وGIF. يفضّل ضغط الصور قبل رفعها.
- تسجيل دخول المدير يتم داخل Worker، وتُحفظ الجلسة في Cookie من نوع HttpOnly وSecure.
- لا يوجد تسجيل عام. بيانات المدير تُضبط كأسرار في Cloudflare.
- احتفظنا بتصميم المتجر الحالي وصور assets الحالية.

مهم: هذه حزمة المصدر التي تحتاج إعداد Cloudflare ونشرها قبل أن تعمل الوظائف. لا ترفعها كملفات ثابتة فقط؛ يجب نشرها كـ Cloudflare Worker مع D1. لا تحتاج هذه النسخة إلى R2.

الإعداد الأول (مرة واحدة)
-------------------------
1) ثبّت Node.js على الكمبيوتر، ثم افتح Terminal داخل مجلد el-halabi-store.
2) سجّل الدخول:
   npx wrangler login
3) أنشئ قاعدة D1:
   npx wrangler d1 create el-halabi-db
   انسخ database_id الذي يظهر، وضعه مكان REPLACE_WITH_D1_DATABASE_ID في wrangler.toml.
4) نفّذ مخطط قاعدة البيانات:
   npx wrangler d1 execute el-halabi-db --remote --file=./schema.sql
5) اضبط بريد صاحب المحل وكلمة المرور كأسرار (لا تضعهما في ملفات HTML):
   npx wrangler secret put ADMIN_EMAIL
   npx wrangler secret put ADMIN_PASSWORD
   npx wrangler secret put SESSION_SECRET
   عند SESSION_SECRET استخدم قيمة عشوائية طويلة لا تقل عن 32 حرفاً. لا تشاركها مع أحد.
6) انشر الموقع والـ API معاً:
   npx wrangler deploy

بعد النشر
----------
- المتجر: https://اسم-المشروع.workers.dev/
- لوحة التحكم: https://اسم-المشروع.workers.dev/admin/
- استخدم البريد وكلمة المرور اللذين أدخلتهما في أسرار Cloudflare.
- أضف المنتجات من لوحة التحكم. عند رفع صورة صغيرة، تُحوّل إلى Data URL وتُحفظ في D1. هذا مناسب لعدد محدود من صور المنتجات؛ لا ترفع صوراً كبيرة أو كثيرة جداً.

تطوير محلي
----------
npx wrangler dev

ملاحظات أمنية وتشغيلية
---------------------
- لا تضع كلمة مرور المدير أو SESSION_SECRET في index.html أو admin.html أو GitHub.
- لا توجد صفحة إنشاء حساب مدير عامة.
- الجلسة صالحة 8 ساعات، وملف تعريف الارتباط HttpOnly وSecure وSameSite=Strict.
- الطلبات العامة تقبل بيانات الزبون وتُخزن في D1؛ راقب الطلبات غير المرغوبة عند تشغيل المتجر.
- النسخة الحالية لا تتضمن إشعارات SMS/WhatsApp ولا تغيير كلمة المرور من داخل اللوحة؛ غيّر ADMIN_PASSWORD من Cloudflare Secrets عند الحاجة.
- خذ نسخة احتياطية من D1 دورياً؛ صور المنتجات الصغيرة مخزنة ضمن بيانات D1.
- لا تنفذ أوامر حذف قواعد البيانات أثناء الإعداد.
